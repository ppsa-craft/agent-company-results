## Description
Build the normalization pipeline that consumes raw adapter output, transforms to canonical `vn-stock-schemas` models, publishes to Redis streams for downstream consumers (S2 Signal Engine), and persists to PostgreSQL for historical queries.

## Acceptance Criteria
- [ ] Normalization engine converts all 4 adapter outputs (VNIndex, CafeF, Vietstock, VNDirect) to unified `PriceData` schema

- [ ] PostgreSQL persistence layer with SQLAlchemy models matching `vn-stock-schemas` PriceData
- [ ] Data validation: reject malformed data, log anomalies, maintain data quality metrics
- [ ] Idempotent writes (upsert on symbol+timestamp) to handle retries

- [ ] Unit tests: normalization logic with VN market sample data
- [ ] Integration test: adapter → normalization → Redis → Postgres flow
