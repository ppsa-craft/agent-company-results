## Title
Build S4 Web UI: S3 API Client, JWT Auth Flow, Protected Routes, WebSocket for Real-Time

## Description
Implement the frontend integration layer: generated API client from S3 OpenAPI spec, complete authentication flow (login, token refresh, logout), route guards, and WebSocket connection for live signal updates.

## Acceptance Criteria
- [ ] OpenAPI client generated from S3 spec (Orval/TypeScript) with typed hooks
- [ ] JWT token management: access token (short-lived), refresh token (httpOnly cookie), auto-refresh
- [ ] Auth flow: login page → S3 `/auth/login` → token storage → redirect to dashboard
- [ ] Protected routes: wrapper component redirects unauthenticated to login
- [ ] WebSocket client: connect to S3 `/ws/signals`, auto-reconnect, message parsing
- [ ] Error handling: API error interceptor, user-friendly toasts, retry logic
- [ ] Loading states: skeleton screens for async data
- [ ] Storybook stories for auth components and data display components
