# Task: pm-s1-002 — S1 VN Market Data Adapters Implementation

## Acceptance Criteria
- VNIndex API adapter implemented with data fetching and error handling
- CafeF adapter implemented with proper data mapping to PriceData schema
- Vietstock adapter implemented with schedule integration
- VNDirect adapter implemented with authentication
- All adapters follow shared interface contract (Adapter base class)
- Each adapter has unit tests

## Implementation Plan
1. Create `adapters/` package in S1 service
2. Create `BaseAdapter` abstract class with `fetch()`, `parse()`, `validate()` interface
3. Implement `VNIndexAdapter` — fetches from VNIndex API
3. Implement `CafeFAdapter` — scrapes/normalizes CafeF data
3. Implement `VietstockAdapter` — connects to Vietstock API
3. Implement `VNDirectAdapter` — authenticates and fetches
4. Write unit tests for each adapter with mock data
5. Add adapter registration in app startup

## Architecture Seam
S1 internal — adapters produce `PriceData[]` published to shared schemas package.
