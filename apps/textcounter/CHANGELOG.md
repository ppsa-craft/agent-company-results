## [1.0.0] - 2026-07-16

### Added
- Word, character, sentence, and paragraph counting
- Reading time estimation (configurable WPM)
- Live-updating web UI with responsive layout
- Copy-to-clipboard for results
- Comprehensive test suite (39 tests)

### Technical
- Built with vanilla JavaScript (ES modules)
- Vite + Vitest for development and testing
- esbuild for production bundling
- No external runtime dependencies
