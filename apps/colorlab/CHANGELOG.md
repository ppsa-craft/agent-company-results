## [1.0.0] - 2026-07-17

### Added
- Color space conversions (HEX, HSL, RGB)
- WCAG 2.1 contrast ratio calculations with AA/AAA pass/fail
- Palette generation algorithms: monochromatic, analogous, complementary, triadic, tetradic, split-complementary
- Web UI with real-time color picker and palette display
- TypeScript types for all color models
- Comprehensive test suite (59 tests, ≥90% branch coverage)
