## [1.0.0] - 2026-07-16

### Added
- Side-by-side text diff with line-by-line comparison
- Word-level inline diff highlighting
- Added/removed/unchanged line classification
- Copy-to-clipboard for each pane
- Clear/reset functionality
- Comprehensive test suite (5 tests)

### Technical
- Built with vanilla JavaScript (ES modules)
- Vite + Vitest for development and testing
- No build step required (runs directly in browser)
- No external runtime dependencies
